# Chrome 扩展设计文档  
## 目标与功能
个人使用的 Chrome 扩展，用于自动分析项目整体进展和特定话题动态。  
系统整合来自以下多源数据：
- 聊天信息（网页聊天记录，静默抓取）
- Jira 数据（任务状态、分配人、依赖等）
- Wiki / Google Sheet / Google Slide（手动选中文本或截图提交）
- 用户主动输入或信息修正（权重更高）

支持“类人脑”的记忆、信息处理、思考与遗忘机制。  

---

## 数据来源与抓取方式
1. **聊天信息**
   - 静默监听当前网页（app.ringcentralcom）indexDB，抓取聊天记录
   - 已实现基本功能 @docs/features/message_analysis_filter.md

2. **Jira 数据**
   - 根据消息关键字，自动调用 Jira REST API 抓取相关任务信息
   - 目前基础的功能实现在 agentThinking 的分析消息、项目过程中会自动识别抓取，参考 @docs/features/agent_thinking.md

3. **Wiki / Sheet / Slide**
   - 用户可右键选中文本 → “添加到记忆”
   - 快捷键或按钮截屏并 OCR 提取文字
   - 调用 Google Sheets / Slides API 获取文档
   - 目前做了 Slide分析功能，但没有任何存储，可以思考是不是要当用户分析的时候同时做存储。相关实现参考 @docs/features/google_slides_analyzer.md

4. **用户输入与修正**
   - 在界面中手动添加/修正信息
   - 高权重存储，影响后续检索排序
   - 完全未实现

---

## 数据存储与管理
- **向量存储**：ChromaDB（可云端部署）
- **存储内容**：文本块向量、元数据（来源、时间戳、标签、重要性）
- **预处理**：
  - 自动摘要（减少冗余）
  - 用户纠正信息完整保留并高权重标记

---

## 记忆与遗忘机制
- **基于使用频率**：低频访问记忆权重逐渐衰减，达到阈值则删除
- **引用频率**：长期未被其他消息关联则标记过时
- **关注列表**：
  - 用户可添加主题/项目并设定保留时长
  - 列表项优先保留，列表外信息按TTL清理
- **时间戳过滤**：到期信息自动归档
- **永久/重要标记**：手动标记则不删除

---

## 分析与思考系统
- **检索增强生成（RAG）架构**：
  - 用户提问 → 将查询转向量 → 向量数据库检索最相关记忆
  - LLM（GPT 等）基于检索结果生成综合回答
- **数据可视化**：
  - Jira 任务进度、依赖状态、风险点
  - 甘特图 / 燃尽图
- **轻量编辑**：
  - 用户可直接修改可视化数据（任务状态、备注）
  - 修改结果同步更新记忆库

---

## 用户界面与交互
1. **静默运行**：后台监听网页和聊天记录
2. **低成本操作**：
   - 右键选中文字 → 添加到记忆
   - 截屏快捷键 → OCR 提取文字
3. **主界面功能**：
   - **项目进展可视化**
   - **风险提示列表**
   - **依赖团队状态**
   - **提问输入框**（自然语言问答）
4. **关注列表管理**：添加主题，设置遗忘时长
5. **编辑与反馈**：修改错误信息，标记重要内容

## 技术选型
- **向量数据库**：ChromaDB / Weaviate / Qdrant
- **嵌入模型**：OpenAI Embeddings / Sentence-Transformers
- **Chrome API**：
  - `contentScripts`（抓取网页内容）
  - `contextMenus`（右键菜单）
  - `tabs.captureVisibleTab`（截屏）
  - `storage`（本地存储）
- **外部 API**：
  - Jira REST API
  - Google Sheets / Slides API
- **安全**：OAuth2 认证、数据加密存储

---

## 数据流示意
1. **采集层**：
   - 内容脚本抓取聊天信息
   - API 获取 Jira / Google 数据
   - 用户手动提交文本或截图
2. **处理层**：
   - 文本清洗、分块
   - 向量化并存储到 ChromaDB
3. **分析层**：
   - 用户查询 → 向量检索 → 相关记忆 + LLM → 答案
4. **输出层**：
   - 可视化进度图
   - 风险/依赖提示
   - 支持编辑和反馈
