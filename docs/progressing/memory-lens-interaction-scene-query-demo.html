Memory Lens 查询如何带上 InteractionScene

前端不调用 LLM 生成“用户现在在做什么”。前端只采集可审计的交互事实：URL、页面字段、可见消息、active element、输入框状态、选中文本和附近文本。Memory Service 再把这些事实归一化为 SceneFrame，并用策略矩阵决定 Lens 是否展示、静默，或交给 Compose Assist。

设计选择
InteractionScene 是结构化 telemetry，不是前端 LLM 总结。这样可复现、可测试、可解释，也避免把页面内容先发给一个额外模型。
