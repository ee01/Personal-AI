1 · 三个平面（LLM 只出现在写入批与睡眠期）

写平面 同步零 LLM 异步批 cheap

  1. /ingest：episode 落地 + claim 归属 + 入队，<20ms，永不阻塞
  2. 三触发门（≥512 tok / 30 min / 会话结束）→ 单飞锁
  3. 上下文装配：本批 + 前 6 条 + top-10 已有 units + peer card
  4. 1 次结构化抽取：units / edges / properties / profile / 触发问句
  5. 零 LLM 去重：精确或 cos≥0.92 → 加固（times_derived++）
  6. 矛盾 → supersede（valid_to / expired_at），不删除
  7. 索引：多视图 FTS（中文分词+trigram）+ 单份 int8 向量

睡眠平面 cheap 为主 smart 兜底

  1. 三重门：≥50 新 units ∧ ≥8h ∧ 空闲 60min（新消息即取消）
  2. A 生命周期算术：R=e^(−t/S)，FSRS-lite 强化，冷却+滞回
  3. B 热度晋升：heat = N_visit + L_interaction + e^(−Δh/24) ≥ 5
  4. C 去重合并 + 触发问句补齐（Batch −50%）
  5. D GA 反思（Σpoignancy≥150）与有证据的 anticipation
  6. E 图维护、GC、投影渲染（.md 不再入索引）

读平面 在线零 LLM

  1. InformationNeedPlanner：scene → needSlots（what）
  2. 多视图召回：正文向量 / 触发问句向量 / 分词 FTS / trigram / PPR / 时间 / 规则
  3. 加权 RRF(k=60) → minmax 归一
  4. score = 权威 × 生命周期 × kind × [.55 rel + .25 R + .20 sal]
  5. 可选 CPU cross-encoder（按 surface）
  6. 自适应阈值 → Autopilot 门控（沿用）→ context_pack
