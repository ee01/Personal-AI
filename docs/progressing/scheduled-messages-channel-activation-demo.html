基座已就绪，但定时消息还需要一条发送通道才能真正送达。请勾选你具备的条件（都可以稍后再配）：

系统将创建：Executor Rule（每分钟领取并发送一条 Bot / AI 消息，结果回写维护表）和 Timeline Sync Rule（每天 05:00 刷新项目里程碑缓存）。仅需一次配置，规则归属在你的 Jira 项目下，随时可在 Jira Automation 中查看。
需要你在该项目拥有 Automation 管理权限
请输入 Project Key（将先预检你的 Automation 权限再创建规则）
✓ 权限预检通过（演示）
🤖 Bot 消息 📊 AI Report ⏰ 个人提醒 🔧 托管 API 行
还没有 Token？按下面步骤获取（约 5 分钟）：
  1. 打开 RingCentral Developer Portal ↗，用公司账号登录
  2. Console → Apps → Create App：选择 REST API App，鉴权方式选 JWT auth flow，勾选 Team Messaging 和 Read Accounts 权限（发送消息 + 解析收件人）
  3. 在 App 详情页复制 Client ID 和 Client Secret
  4. Console → Credentials → JWT：为该 App 生成一条 Personal JWT（Production 环境）
开启 AsMe 需要填写完整的 Client ID、Client Secret 和 JWT
⚠️ 凭据写入维护表 Config 子表，仅由你自己的 AppScript 读取使用（不再经由 Jira / Dify 传递）；若维护表已域共享，请知悉可见范围（凭据存储加固见 plan P2）。
跳过后系统仍可创建「草稿（Paused）」消息；之后随时可在消息列表的「通道状态」卡中完成激活。
