# 自定义提示词和用户上下文功能说明

## 功能概述

本次更新为 Personal AI 扩展添加了强大的自定义提示词和用户上下文配置功能，让用户能够个性化定制分析行为，提供更精准、更符合个人工作场景的分析结果。

## 主要功能

### 1. 自定义提示词配置
- **消息分析提示词**: 自定义消息分析的特定要求和关注点
- **项目分析提示词**: 自定义项目分析的特定要求和关注点

### 2. 用户上下文配置
- **个人基本信息**: 姓名、邮箱、职位、部门、地点
- **汇报关系**: 直接上级和关键利益相关者信息
- **团队信息**: 团队名称、使命、成员、工作时间等
- **工作重点**: 主要关注领域、业务域、关键指标
- **沟通偏好**: 受众类型、沟通风格、文化背景等
- **分析偏好**: 消息和项目分析的重点领域设置

## 使用方法

### 1. 打开配置界面
1. 在 Google Slides 页面打开扩展弹窗
2. 点击"分析 Slide 项目信息并更新"按钮旁边的齿轮图标 ⚙️
3. 配置窗口将以弹窗形式打开

### 2. 配置自定义提示词
在"自定义提示词"标签页中：
- **消息分析提示词**: 输入您希望在分析消息时特别关注的要求
- **项目分析提示词**: 输入您希望在分析项目时特别关注的要求

示例：
```
消息分析提示词: 特别关注项目风险、时间线延迟和资源分配问题
项目分析提示词: 重点分析项目依赖关系、里程碑达成情况和团队协作效率
```

### 3. 配置个人信息
在"个人信息"标签页中填写：
- 姓名、邮箱、职位等基本信息
- 这些信息将帮助 AI 更好地理解您的角色和职责

### 4. 配置汇报关系
在"汇报关系"标签页中设置：
- 直接上级信息（姓名、职位、汇报频率）
- 关键利益相关者信息
- 点击"添加利益相关者"可添加多个相关人员

### 5. 配置团队设置
在"团队设置"标签页中配置：
- 团队基本信息（名称、使命、规模）
- 团队成员信息
- 工作时间和时区设置

### 6. 配置工作重点
在"工作重点"标签页中设置：
- 主要关注领域（如：项目管理、质量保证、风险控制等）
- 业务域（如：电商、金融、教育等）
- 关键指标（如：交付时间、质量分数、客户满意度等）
- 风险容忍度

### 7. 配置分析偏好
在"分析偏好"标签页中设置：
- 消息分析重点领域
- 项目分析重点领域
- 忽略的话题
- 紧急关键词

## 配置效果

配置完成后，所有的分析功能都会自动应用您的个性化设置：

### 1. 消息分析增强
- 分析结果会结合您的角色和职责
- 根据您的关注点提供更精准的重要性判断
- 考虑您的汇报关系提供相关的行动建议

### 2. 项目分析增强
- 基于您的工作重点进行风险评估
- 结合团队情况提供协作建议
- 根据您的业务域提供专业见解

### 3. 会议分析增强
- 考虑参会人员与您的关系
- 基于您的关注领域提取关键信息
- 提供符合您沟通风格的总结

### 4. 文档分析增强
- 根据您的专业领域进行深度分析
- 考虑文档与您工作的相关性
- 提供个性化的行动建议

## 数据存储

所有配置信息都安全地存储在浏览器的本地存储中，不会上传到任何服务器。您可以随时修改或重置配置。

## 重置配置

如需重置所有配置到默认状态，可以在配置界面底部点击"重置为默认设置"按钮。

## 技术实现

### 文件结构
- `src/modals/prompt-config.tsx`: 配置界面 React 组件
- `src/agentThinking.ts`: 集成用户配置到分析流程
- `src/popup.tsx`: 添加配置按钮
- `src/manifest.json`: 添加配置页面到可访问资源

### 存储结构
配置信息存储在 `chrome.storage.local` 中，包含：
- `userContextConfig`: 用户上下文配置
- `customPrompts`: 自定义提示词配置
- `lastUpdated`: 最后更新时间

## 注意事项

1. 配置信息仅在本地存储，不会同步到其他设备
2. 建议定期备份重要的配置信息
3. 配置越详细，分析结果越精准
4. 可以根据工作变化随时调整配置
