# 项目进度仪表盘使用指南

*最后更新: 2026-04-30*

## 概述

项目进度仪表盘是 Personal AI 扩展内的项目工作台。当前版本以本地鱼骨时间线为主，用来维护项目、里程碑、任务、Jira 链接和项目健康摘要。

## 🚀 如何访问项目仪表盘

### 方法1：从实体记忆项目入口打开（推荐）

1. 打开 `memory-exploring.html`
2. 进入项目实体列表或项目详情
3. 点击项目卡片上的仪表盘入口
4. 仪表盘会在独立窗口中打开

### 方法2：直接访问HTML文件
- 直接访问：`chrome-extension://[扩展ID]/project-dashboard.html`

## 🎯 主要功能

### 1. 项目概览
- **健康摘要**：每个项目卡片前置“正常 / 需关注 / 需处理 / 待规划”状态。
- **关键指标**：完成任务数、阻塞任务数、过期任务数、近 7 天到期任务、下个里程碑。
- **鱼骨时间线**：展示里程碑、依赖、设计任务、开发任务和平台状态。

### 2. 数据同步与管理
- **⚡ 同步数据**：当前是模拟同步结果，真实 Jira/GitHub/Confluence 同步仍待接入
- **🔄 刷新数据**：手动刷新本地缓存数据
- **📄 导出报告**：导出当前仪表盘项目数据为 JSON 报告
- **📥 导入报告**：从 JSON 报告导入项目数据，支持合并或替换当前项目列表
- **本地持久化**：项目、里程碑、任务和导入结果会保存到 `chrome.storage.local`

### 3. 实时状态监控
- **阻塞提示**：任务状态为 `blocked` 时，项目卡片显示“需处理”
- **ETA 提醒**：未完成任务超过 ETA 计入过期；7 天内到期计入近期关注
- **里程碑跟踪**：展示最近的未来里程碑日期

## 当前界面

目前仪表盘提供：

- 项目卡片列表
- 项目健康摘要
- 鱼骨时间线
- 新增项目弹窗
- 新增任务弹窗
- 任务详情编辑弹窗
- JSON 导入/导出

## 🔧 技术特性

### 智能数据收集
- **被动收集**：网页浏览时自动识别项目相关信息，并回链到记忆界面
- **用户输入**：支持手动添加和编辑项目信息
- **后续接入**：真实 Jira/GitHub/Confluence API 同步

### 类人脑记忆机制
- **本地项目工作台**：仪表盘数据保存在 `chrome.storage.local`
- **长期记忆**：项目实体和上下文由 Memory Service 管理
- **后续方向**：把本地项目与 Memory Service watched projects 合并

### 当前限制
- 项目数据仍保存在当前浏览器本地
- 多设备同步、多人协作和冲突解决尚未实现
- “同步数据”按钮当前只返回模拟同步结果

## 🎨 界面设计

### 响应式布局
- **桌面优化**：1200x900 像素窗口体验最佳
- **移动适配**：小屏幕会压缩项目卡片和健康摘要布局

### 用户体验
- **直观导航**：清晰的功能分区和操作流程
- **快速操作**：一键同步、导出、刷新
- **实时反馈**：操作状态和结果即时展示

## 🔄 数据流程

### 输入源
1. **手动输入**：用户创建项目、里程碑和任务
2. **JSON 报告**：导入/导出仪表盘项目数据
3. **网页浏览**：Web Intelligence 和 Context Recall 识别项目相关信息
4. **Slides 分析**：Google Slides Analyzer 识别项目状态更新
5. **后续接入**：Jira、GitHub、Confluence 等权威数据源

### 处理流程
1. **数据维护**：在仪表盘里创建/编辑项目数据，或导入 JSON 报告
2. **本地持久化**：保存到 `chrome.storage.local`
3. **健康计算**：按阻塞、过期、近期到期、完成数和里程碑生成摘要
4. **可视化渲染**：渲染项目卡片、健康摘要和鱼骨时间线

### 输出形式
1. **项目仪表盘**：项目卡片、健康摘要、鱼骨时间线
2. **JSON 报告**：可导出并回读导入
3. **后续方向**：状态更新草稿、真实数据同步、风险预测

## 🚀 快速开始

### 第一次使用
1. **安装扩展**：确保个人AI助手扩展已正确安装
2. **打开仪表盘**：从 `memory-exploring.html` 的项目入口打开，或直接访问 `project-dashboard.html`
3. **查看健康摘要**：先确认是否有阻塞、过期或近期到期任务
4. **点击时间线空白处**：快速新增任务
5. **点击任务卡片**：编辑状态、ETA、描述和 Jira 链接

### 日常使用
1. **定期同步**：点击"同步数据"获取最新信息
2. **监控进度**：查看项目整体进度和关键指标
3. **导出备份**：使用“导出全部”或项目卡片上的“导出当前项目”生成 JSON 备份
4. **导入回读**：使用“导入报告”导入 JSON，按提示选择合并或替换
5. **识别风险**：优先处理“需处理”项目中的阻塞和过期项
6. **团队协调**：用任务详情里的平台负责人和 Jira 链接追踪责任人

### 高级功能
1. **自定义筛选**：根据时间、状态、人员筛选信息
2. **批量操作**：同时处理多个任务或里程碑
3. **趋势分析**：基于历史数据分析项目趋势
4. **智能推荐**：AI驱动的项目优化建议
