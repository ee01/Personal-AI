# 📊 项目进度仪表盘使用指南

## 概述

项目进度仪表盘是个人AI助手扩展的核心功能之一，提供了完整的项目管理和可视化能力。基于类人脑信息处理理念，该仪表盘能够智能地收集、分析和展示项目信息。

## 🚀 如何访问项目仪表盘

### 方法1：通过Chrome扩展主界面（推荐）

1. **点击扩展图标**：在Chrome浏览器右上角点击个人AI助手扩展图标
2. **打开仪表盘**：在弹出的菜单中点击 "📊 项目进度仪表盘" 按钮
3. **独立窗口**：仪表盘会在一个新的独立窗口中打开（1200x900像素）

### 方法2：直接访问HTML文件
- 直接访问：`chrome-extension://[扩展ID]/project-dashboard.html`

## 🎯 主要功能

### 1. 项目概览
- **整体进度**：显示项目完成百分比和进度条
- **关键指标**：里程碑数量、团队成员、风险数量、依赖关系
- **项目选择器**：支持在多个项目间切换

### 2. 数据同步与管理
- **⚡ 同步数据**：从Jira、GitHub、Confluence等数据源同步最新信息
- **🔄 刷新数据**：手动刷新本地缓存数据
- **📄 导出报告**：导出当前仪表盘项目数据为 JSON 报告
- **📥 导入报告**：从 JSON 报告导入项目数据，支持合并或替换当前项目列表

### 3. 实时状态监控
- **项目状态**：规划中、进行中、风险中、已完成
- **里程碑跟踪**：按时、有风险、延迟、已完成
- **团队工作负载**：实时显示团队成员的工作状态

## 🔧 技术特性

### 智能数据收集
- **被动收集**：网页浏览时自动识别项目相关信息
- **主动获取**：通过API同步Jira、GitHub等平台数据
- **用户输入**：支持手动添加和编辑项目信息

### 类人脑记忆机制
- **短期记忆**：临时缓存当前操作的项目数据
- **长期记忆**：持久化存储重要的项目历史信息
- **智能遗忘**：基于重要性和时间自动清理过期数据

### 实时协作
- **数据同步**：多设备间项目数据实时同步
- **变更通知**：项目更新时智能提醒相关人员
- **冲突解决**：自动处理数据更新冲突

## 🎨 界面设计

### 响应式布局
- **桌面优化**：1200x900像素的最佳体验
- **移动适配**：自动适应小屏幕设备
- **暗色模式**：支持系统主题切换

### 用户体验
- **直观导航**：清晰的功能分区和操作流程
- **快速操作**：一键同步、导出、刷新
- **实时反馈**：操作状态和结果即时展示

## 🔄 数据流程

### 输入源
1. **Jira**：任务、里程碑、团队分配
2. **GitHub**：代码提交、PR状态、Issues
3. **Confluence**：文档、需求、决策记录
4. **网页浏览**：自动识别项目相关信息
5. **手动输入**：用户直接创建和编辑

### 处理流程
1. **数据收集**：从多个源头获取原始数据
2. **智能分析**：AI驱动的内容理解和分类
3. **关系提取**：识别任务、人员、时间间的关系
4. **优先级评估**：基于重要性和紧急度排序
5. **可视化渲染**：生成图表和报告

### 输出形式
1. **实时仪表盘**：动态更新的可视化界面
2. **分析报告**：JSON 格式的详细项目分析与回读导入
3. **提醒通知**：基于规则的智能提醒
4. **趋势预测**：基于历史数据的未来预测

## 🚀 快速开始

### 第一次使用
1. **安装扩展**：确保个人AI助手扩展已正确安装
2. **打开仪表盘**：点击扩展图标 → "📊 项目进度仪表盘"
3. **选择项目**：从下拉列表中选择要查看的项目
4. **探索功能**：尝试同步数据、导出报告等功能

### 日常使用
1. **定期同步**：点击"同步数据"获取最新信息
2. **监控进度**：查看项目整体进度和关键指标
3. **导出备份**：使用“导出全部”或项目卡片上的“导出当前项目”生成 JSON 备份
4. **导入回读**：使用“导入报告”导入 JSON，按提示选择合并或替换
5. **识别风险**：关注风险数量和状态变化
6. **团队协调**：了解团队成员工作负载和可用性

### 高级功能
1. **自定义筛选**：根据时间、状态、人员筛选信息
2. **批量操作**：同时处理多个任务或里程碑
3. **趋势分析**：基于历史数据分析项目趋势
4. **智能推荐**：AI驱动的项目优化建议
