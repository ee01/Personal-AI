# AI 智能消息分析过滤功能

*最后更新: 2024-12-20*

## 功能概述

AI 智能消息分析过滤功能是 Personal AI Chrome 插件的核心功能之一，它能够智能分析聊天消息，自动过滤出重要信息，并提供相应的通知和存储服务。该功能支持多种分析模式，包括智能Agent系统、关注项匹配、@我通知等，为用户提供个性化的消息管理体验。

## 主要特性

### 1. 智能消息过滤
- 基于用户自定义规则自动过滤重要消息
- 支持多种过滤条件：关键词匹配、发送者匹配、@提及等
- 智能排除无关消息，减少信息噪音

### 2. 多模式分析系统
插件支持三种不同的分析模式：

#### 智能Agent模式 (agentThinking)
- 使用先进的AI代理系统进行消息分析
- 支持消息降噪和上下文分析
- 批量处理多个群组消息
- 提供详细的处理统计信息

#### Agent工作流模式 (agentWorkflow)
- 使用多Agent协调器模式进行消息分析
- 支持智能关注项匹配和自动通知推送
- 完整支持机器人消息推送和@我功能
- 多专业化Agent按优先级协同工作
- 支持实体关系分析和外部服务集成
- 轻量级架构，专注于效率和准确性

#### 普通模式
- 传统的LLM分析方式
- 支持按群组分析或批量分析
- 灵活的分析配置选项

### 3. 上下文理解
- 智能分析消息的上下文关系
- 理解群组内的对话流程
- 识别消息的相关性和重要性
- 提供基于上下文的总结和推理

### 4. 实体信息提取
自动提取消息中的关键实体信息：
- **人物**：消息中提到的人员
- **项目**：相关的项目名称和描述
- **话题**：讨论的主题和内容
- **行动项**：需要执行的任务和动作
- **情感**：消息的情感倾向（积极/消极/中性）
- **类别**：消息的分类（决策、讨论、公告等）

### 5. 智能通知系统
- 根据消息重要性自动推送到指定渠道
- 支持多种通知方式
- **@我功能**：支持针对特定关注项配置是否@用户
- **智能关注项匹配**：使用LLM智能分析消息是否匹配用户关注的话题
- **个性化通知**：根据关注项配置决定通知方式和内容
- 可配置的通知规则和优先级
- 智能审核机制，避免误报

### 6. 关注项管理和@我功能

#### 关注项配置
- **自定义关注规则**：用户可以配置多个关注项，每个关注项包含具体的匹配规则
- **推送配置**：每个关注项可以独立配置是否推送Glip消息
- **@我配置**：每个关注项可以独立配置是否在通知中@用户
- **过期管理**：支持设置关注项的过期时间，自动清理过期项目
- **优先级排序**：支持拖拽排序，调整关注项的优先级

#### @我功能特性
- **智能判断**：系统根据关注项的@我配置智能决定是否在机器人消息中@用户
- **视觉标识**：在关注项列表中，启用@我的项目会显示红色的"@"标识（`Glip ✓ @`）
- **依赖关系**：@我功能依赖于推送Glip消息功能，只有启用推送的关注项才能配置@我
- **兼容性**：支持团队模式和个人模式的机器人通知
- **默认行为**：新增关注项时，@我选项默认选中

#### 关注项匹配逻辑
- **LLM智能分析**：使用大语言模型分析消息内容是否匹配关注项规则
- **上下文理解**：结合消息发送者、群组信息和消息内容进行综合判断
- **置信度评估**：为每个匹配结果提供置信度评分，提高判断准确性
- **规则原文匹配**：返回具体匹配的规则原文，便于用户理解

#### 数据管理
- **导出功能**：支持将关注项配置导出为XML格式
- **导入功能**：支持从XML文件导入关注项配置
- **数据备份**：自动保存关注项配置，防止数据丢失
- **批量管理**：支持批量编辑和删除关注项

### 7. 消息存储管理
- 将重要消息存储到向量数据库
- 支持后续检索和分析
- 结构化存储消息元数据
- 便于知识管理和历史查询

### 7. 回复建议
- 基于消息上下文提供智能回复建议
- 考虑群组氛围和对话风格
- 支持多语言回复建议
- 可选的回复策略

### 8. 定时分析
- 支持定时任务自动分析新消息
- 可配置的分析频率
- 任务状态监控和管理
- 支持手动启动和停止

### 9. 进度跟踪
- 实时显示分析进度
- 详细的处理统计信息
- 可视化进度指示器
- 错误处理和重试机制

## 配置选项

### 环境配置
```javascript
// 分析类型配置
ANALYSIS_TYPE: 'agentThinking' | 'agentWorkflow' | 'normal'

// 是否启用机器人通知
ENABLE_BOT: true | false

// 是否按群组分析
ANALYZE_BY_GROUP: true | false

// LLM类型配置
LLM_TYPE: 'local' | 'cloud'

// 是否启用发送前审核
LLM_REVIEW_BEFORE_SEND: true | false
```

### 关注项目配置
用户可以自定义关注的消息类型：
```javascript
concernedItems: [
  {
    text: 'recording 项目在 RCV mobile 中的相关信息，特别是 BE 依赖部分的完成情况',
    pushToGlip: true
  },
  {
    text: '聊到关于公司政策，也可以是政策相关的八卦消息',
    pushToGlip: false
  },
  {
    text: 'Sophia (Jinmei) Lin 发送的所有消息',
    pushToGlip: true
  },
  {
    text: '任何明确 @我 的消息，或者提到我的名字的消息',
    pushToGlip: true
  }
]
```

## 技术架构

### 核心组件
- **消息分析器**：负责消息的智能分析和过滤
- **Agent协调器**：管理多个专业化Agent的协同工作（agentWorkflow模式）
- **关注项匹配器**：使用LLM智能匹配用户关注的话题
- **实体提取器**：提取消息中的关键实体信息
- **向量存储**：使用Chroma向量数据库存储消息
- **通知系统**：处理消息推送和通知，支持@我功能
- **进度管理器**：管理分析进度和状态
- **关注项管理器**：管理用户自定义的关注规则和配置

### 数据流程
1. **消息输入** → 2. **关注项匹配** → 3. **智能分析** → 4. **实体提取** → 5. **重要性评估** → 6. **@我判断** → 7. **存储/通知**

#### 详细流程说明
- **消息输入**：接收来自群组的消息数据
- **关注项匹配**：使用LLM分析消息是否匹配用户配置的关注项
- **智能分析**：根据选择的分析模式进行深度分析
- **实体提取**：从消息中提取人物、项目、时间等关键实体
- **重要性评估**：评估消息的重要性和存储必要性
- **@我判断**：根据关注项配置决定是否在通知中@用户
- **存储/通知**：将重要消息存储到知识库并发送通知
