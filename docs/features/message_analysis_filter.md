# AI 智能消息分析过滤功能

## 功能概述

AI 智能消息分析过滤功能是 Personal AI Chrome 插件的核心功能之一，它能够智能分析聊天消息，自动过滤出重要信息，并提供相应的通知和存储服务。

## 主要特性

### 1. 智能消息过滤
- 基于用户自定义规则自动过滤重要消息
- 支持多种过滤条件：关键词匹配、发送者匹配、@提及等
- 智能排除无关消息，减少信息噪音

### 2. 多模式分析系统
插件支持三种不同的分析模式：

#### 智能Agent模式 (agentThinking)
- 使用先进的AI代理系统进行消息分析
- 支持消息降噪和上下文分析
- 批量处理多个群组消息
- 提供详细的处理统计信息

#### Agent工作流模式 (agentWorkflow)
- 使用智能Agent工作流系统
- 自动处理消息存储逻辑
- 集成化的消息处理流程

#### 普通模式
- 传统的LLM分析方式
- 支持按群组分析或批量分析
- 灵活的分析配置选项

### 3. 上下文理解
- 智能分析消息的上下文关系
- 理解群组内的对话流程
- 识别消息的相关性和重要性
- 提供基于上下文的总结和推理

### 4. 实体信息提取
自动提取消息中的关键实体信息：
- **人物**：消息中提到的人员
- **项目**：相关的项目名称和描述
- **话题**：讨论的主题和内容
- **行动项**：需要执行的任务和动作
- **情感**：消息的情感倾向（积极/消极/中性）
- **类别**：消息的分类（决策、讨论、公告等）

### 5. 智能通知系统
- 根据消息重要性自动推送到指定渠道
- 支持多种通知方式
- 可配置的通知规则和优先级
- 智能审核机制，避免误报

### 6. 消息存储管理
- 将重要消息存储到向量数据库
- 支持后续检索和分析
- 结构化存储消息元数据
- 便于知识管理和历史查询

### 7. 回复建议
- 基于消息上下文提供智能回复建议
- 考虑群组氛围和对话风格
- 支持多语言回复建议
- 可选的回复策略

### 8. 定时分析
- 支持定时任务自动分析新消息
- 可配置的分析频率
- 任务状态监控和管理
- 支持手动启动和停止

### 9. 进度跟踪
- 实时显示分析进度
- 详细的处理统计信息
- 可视化进度指示器
- 错误处理和重试机制

## 配置选项

### 环境配置
```javascript
// 分析类型配置
ANALYSIS_TYPE: 'agentThinking' | 'agentWorkflow' | 'normal'

// 是否启用机器人通知
ENABLE_BOT: true | false

// 是否按群组分析
ANALYZE_BY_GROUP: true | false

// LLM类型配置
LLM_TYPE: 'local' | 'cloud'

// 是否启用发送前审核
LLM_REVIEW_BEFORE_SEND: true | false
```

### 关注项目配置
用户可以自定义关注的消息类型：
```javascript
concernedItems: [
  {
    text: 'recording 项目在 RCV mobile 中的相关信息，特别是 BE 依赖部分的完成情况',
    pushToGlip: true
  },
  {
    text: '聊到关于公司政策，也可以是政策相关的八卦消息',
    pushToGlip: false
  },
  {
    text: 'Sophia (Jinmei) Lin 发送的所有消息',
    pushToGlip: true
  },
  {
    text: '任何明确 @我 的消息，或者提到我的名字的消息',
    pushToGlip: true
  }
]
```

## 使用场景

### 1. 项目管理
- 自动识别项目相关的讨论和更新
- 跟踪项目依赖和完成情况
- 及时通知项目状态变化

### 2. 团队协作
- 识别需要关注的重要消息
- 自动过滤无关信息
- 提供智能回复建议

### 3. 知识管理
- 自动存储重要信息到知识库
- 结构化组织消息内容
- 支持后续检索和分析

### 4. 通知管理
- 智能过滤通知内容
- 避免信息过载
- 确保重要信息不遗漏

## 技术架构

### 核心组件
- **消息分析器**：负责消息的智能分析和过滤
- **实体提取器**：提取消息中的关键实体信息
- **向量存储**：使用Chroma向量数据库存储消息
- **通知系统**：处理消息推送和通知
- **进度管理器**：管理分析进度和状态

### 数据流程
1. 消息输入 → 2. 规则过滤 → 3. 智能分析 → 4. 实体提取 → 5. 重要性评估 → 6. 存储/通知
