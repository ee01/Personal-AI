# 贡献指南

感谢您对Personal AI项目的关注和贡献！本文档提供了参与项目贡献的指南。

## 文档贡献

### 更新现有文档

1. 确保了解文档的目标和范围
2. 保持文档风格一致
3. 提交前检查格式和链接
4. 使用Markdown格式化功能增强可读性

### 创建新功能文档

为每个新功能创建两个文档:

1. `docs/features/feature_name.mdc` - 功能设计与实现文档
2. `docs/features/feature_name_prompt.mdc` - 开发过程中的关键AI对话记录

## 代码贡献

### 开发流程

1. Fork仓库并创建分支
2. 编写代码和测试
3. 确保代码符合项目风格指南
4. 提交前运行测试确保功能正常
5. 提交Pull Request并等待审查

### 代码风格

- 遵循TypeScript代码规范
- 使用ESLint和Prettier保持代码格式一致
- 添加适当的注释和文档字符串
- 优先复用现有组件和工具

## 文档即代码理念

本项目采用"文档即代码"理念，意味着:

1. 文档与代码同等重要，应同步更新
2. 文档变更应通过版本控制系统跟踪
3. 代码审查过程应包含对文档更新的审查
4. 自动化工具应用于保持文档的准确性和最新性

## Prompt记录指南

记录与AI的关键对话时:

1. 记录日期和背景上下文
2. 包含原始prompt全文
3. 记录重要的思考过程和设计决策
4. 排除不必要的调试和小修改交互
5. 将关键实现细节与最终决策整理归纳

## 提交信息规范

提交信息应遵循以下格式:

```
<type>(<scope>): <subject>

<body>

<footer>
```

类型(type)包括:
- feat: 新功能
- fix: 错误修复
- docs: 文档更改
- style: 格式修改
- refactor: 代码重构
- test: 测试相关
- chore: 构建过程或辅助工具变动
