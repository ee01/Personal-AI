设计重点

不是会议摘要，而是 outcome closure。
Agenda-aware 会前

先知道这场会原本要解决什么，而不是事后从 transcript 猜重点。

Mention 不等于 Resolved 会中

会中只显示提及状态；会后才根据证据装订为 resolved / partial / carry-over。

只读优先 信任边界

复制、打开、带到下次都不会自动写 Calendar、Jira、RingCentral 或外部 AI。

下一次继续 记忆复用

未闭环项进入下一次会前准备和 Ask source card，不变成新的 review queue。
