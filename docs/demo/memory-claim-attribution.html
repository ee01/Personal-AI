Personal AI · Runtime UX

记忆主张归属，是后台门禁，不是一条新的用户旅程。

普通消息发送后没有新增动作。只有当 AI 建议、他人观点或假设会改变回答、画像或承诺判断时，既有 Ask / Memory Lens 才出现一条可展开的归属回执。

当前实现口径 Memory Lens 的纠错只写 Personal AI 派生归属；不修改原始消息，也不写回 Glip、网页或其他外部系统。

P0 · 默认路径

用户照常发消息。界面什么都不多。

没有「记住这段」，没有归属确认弹窗，也没有待审队列。价值发生在写入前：系统先保存原文，再决定哪些句子有资格成为画像、事实或承诺。

01
原始消息照常留存

保留原文、来源和时间，不因后续判断或纠错而改写。

02
后台切分主张

识别「我的决定」「另一位 AI 建议」「先假设」三种不同责任边界。

单一明确自述直接通过，用户不会看到任何归属 UI。

03
高责任写入失败关闭

AI 建议不成为用户偏好，假设不成为当前事实；归属不明时宁可暂不派生。
