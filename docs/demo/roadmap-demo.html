Demo 说明

  • Jira 查询 / 创建（直连 API 与 Agent 执行器双路径）/ AI 缩写 / 协作同步均为模拟
  • 创建 Jira 双路径：Prompt 留空＝按下方字段直连 Jira API；填写＝交给所选 Agent 执行器（可用技能、自动填当前 Sprint 等动态字段），此时下方字段占位变「自动」，已填的值作为约束带给 Agent；执行器无配置时展示引导入口。fixVersion：配置了发布时间表后按各任务 Target End 落点自动匹配 release name（同一 release 直接填入，跨 release 时逐条匹配、列表内逐行显示绿色 chip，可输固定值覆盖）
  • Assignee 映射：弹窗内新增 Assignee 行 —— 任务 Owner 优先，没写 Owner 的任务回落到创建人；在「配置映射…」里为系统人员/创建者补全 Firstname Lastname（两个词以上的名字自动推断）。直连 API 时转成 firstname.lastname 填 assignee（未映射的留空并橙色提示）；Agent 模式把字段约束 + 人员名单一并写入 Prompt，可点「查看将发送的完整 Prompt」预览。配置后全站（选人列表 / 人员视图 / 提示 / 协作日志）都展示映射后的实名
  • Bar 可拖动 / 左右把手伸缩 / 上下换行，按天吸附
  • 单击 bar 展开/收起；双击编辑备注名（✦ AI 缩写）；备注名换行展示、bar 自动增高；hover 显示原 ticket 名
  • 悬浮：bar 左侧 ＋ 添加任务，右侧 ◆＋ 添加阶段节点 / 外部依赖，右上角 × 退回 Backlog（草稿为删除）
  • 阶段节点（Design/Stage/Production/自定义）以菱形标记显示在 bar 下方的标记轨上，按日期定位、可超出 bar 范围；标记可左右拖动改期（按天吸附，拖到边缘自动滚动），单击则打开编辑器改日期 / 改名 / 删除
  • 外部依赖不是子任务，可不填 Jira 直接手动添加，也可绑定 Jira ticket 模拟读取其 Target End 作为 ETA；缺少 ETA 时 bar 上的 🔗 角标会持续闪烁提醒，点击角标可补齐 ETA / 催办 / 删除；一旦有了 ETA，会自动并入标记轨（圆形链接标记），同样可左右拖动调整 ETA
  • Backlog 搜索：按标题 / Key / 备注名 / 类型 / Quarter 过滤，多个关键词空格分隔需全部命中；Esc 清空
  • 新建条目：手动创建不依赖 Jira 的 Backlog 条目（可填类型 / Quarter / 预估 / Target 日期），卡片显示 DRAFT 且为虚线描边，hover 右上角 × 可删除
  • 任务可选 Owner：标题里输入 @ 触发建议（可手输自定义），或点输入框左侧头像；直接 Enter 则跳过。Owner 数据来自团队成员表，新名字自动加入；双击任务条可改 Owner。选人浮层搜索框置顶、打开即聚焦，列表限高可滚动，↑↓ + Enter 快速选择，下方空间不足时自动向上翻转
  • 新增任务默认从今天开始、两周长；草稿任务条不再叠创建者名，hover 时在条外浮出灰色「xxx created」
  • 打开 Jira：主/子任务条 hover 左上角出现 ↗ 圆钮，点击新开对应 issue；⌘/Ctrl+单击任务条等效（草稿无 issue 不显示）
  • 人员视图：按人查看任务（近 2 周 / 全部），可添加成员、双击改名、移除空闲成员
  • 清理过期：过期 Epic 回退 Backlog（保留子任务记录，重拖回任务视图可还原），过期子任务从任务视图清理
  • 拖入排期：带 Target 日期的卡片按 Target start/end 落位，其余按松手位置 + 预估
  • 拖动 / 伸缩 Epic 后自动回写 Jira：新的起止日期以后台任务同步到该 issue 的 Target Start/End（服务端 env 配置 Jira 凭据；连续拖动只同步最后一次，演示为模拟）
  • 导入 Task（创建 Jira 左侧浅蓝按钮）：拉取甘特上各主任务名下的 Jira Task，按 Key 去重、已存在的不重复导入。日期兜底：Task 未填 Target Start/End 时与主任务同起止；只填其一时按两周落位，且不超出主任务范围
  • 顶栏 JQL 右侧 ✎ 可编辑团队 JQL（下次导入生效）
  • 发布时间表标尺：✎ 弹窗内可为团队配置 Google Sheet 发布时间表（Release / Phase / Date 三列，悬停「查看示例」看格式）。填完地址自动读取，下方「标尺阶段」列出表中出现的阶段：勾选 = 在标尺上展示，⚑ = 作为 release 分割节点（有 FF 默认 FF，分割节点必定展示）。未读取就直接保存也可以，保存时兜底读取并按默认（FF 分界 + 全部展示）。配置后表头换成双轴：Sprint 行为主轴（release 名替代月份、按分割节点切段、当前 Sprint 高亮橙色），月份降为细行副轴（quarter 标签移除）；正文竖线换成 Sprint 分界实线 + 阶段虚线；Pro 刻度直接标注日期；拖动任务时提示可赶的最近 Sprint。Nova Brandy 已预配置（演示只展示 FF / Stage / Pro 三个阶段），RCV Mobile 未配置可体验完整引导流程；清除配置即恢复月份标尺
  • Release 过滤：弹窗内可过滤小版本 —— 预设「仅大版本（尾号 0）」一键保留 26.3.320 这类、过滤 26.3.325 这类；「自定义」用通配符（*0, RIO * 逗号分隔任一匹配即保留），/…/ 包裹按正则。任何档位下方都实时预览保留 / 过滤名单（被滤的划线展示）；规则非法或把 release 全滤掉时自动兜底为不过滤。被滤掉的 release 不参与 Sprint 分段、刻度与可赶 Sprint 提示。Brandy 预设「仅大版本」，可在弹窗切回「全部」对比
  • 标尺临时切换：配置了发布时间表后，工具栏出现 Sprint / 月份 小开关，可随时切回月份刻度对日期（切换态为浅蓝提示）。只影响自己的当前视图，不改团队配置、不同步给他人、刷新即恢复；月份模式下「可赶 Sprint」提示照常保留。未配置的团队不显示该开关
  • 颜色按「当前月」区分过去 / 当前 / 未来
  • 顶栏 LIVE 头像为协作示意（hover 头像可见用户名），加载约 7 秒 / 16 秒后模拟同事实时编辑
  • 头像左侧为协作同步日志：滚动展示其他成员的最新一条编辑（时间 + 人 + 动作 + 主任务缩写），新日志滚入、旧日志滚出，不持续滚动历史
  • RCV Mobile 团队为空，可体验完整导入流程
  • 除 AI prompt、执行器选择与 Assignee 映射外不持久化，刷新即重置
