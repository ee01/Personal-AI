Installation Guide

Two Ways to Start Using Personal AI

1

Install from Chrome Web Store

Recommended

Install the official version from Chrome Web Store - automatic updates, secure and reliable.

Step 1

Visit Chrome Web Store

Click the button below or search for "Personal AI" in Chrome Web Store

Go to Chrome Web Store
Step 2

Click "Add to Chrome"

On the extension page, click the blue "Add to Chrome" button

Step 3

Confirm Installation

In the popup, click "Add extension" to complete the installation

Step 4

Start Using

Click the extension icon in the toolbar, complete the initial setup, and start using

2

Manual Installation (Developer Mode)

Advanced

For development, testing, or when the extension is not yet available in the store.

Step 1

Download Source Code

Download from GitHub or receive from the project administrator:

Download Latest Version
Step 2

Extract Files

Extract the downloaded .zip file to a local folder (remember this path)

Step 3

Open Extensions Page

Enter in Chrome address bar: chrome://extensions/

Step 4

Enable Developer Mode

Toggle the "Developer mode" switch in the top right corner

Step 5

Load Extension

Click "Load unpacked" button, select the extracted folder

Step 6

Start Using

The extension will appear in the list, click the icon in the toolbar to start using

⚠️ Important Notes

  • Developer mode installed extensions do not auto-update, need manual update
  • Chrome may show "Disable developer mode extensions" warning, this is normal
  • Keep the extension folder, do not delete, or it will become unavailable
  • Recommended for Chrome version 90 and above
3

Initial Setup

Required

Complete these setup steps after installation to unlock all features.

Step 1

Configure API Keys

In the settings page, add necessary AI service API Keys (such as OpenAI, Claude, etc.)

Step 2

Grant Permissions

As prompted, grant necessary permissions (such as accessing Google Sheets, Jira, etc.)

Step 3

Initialize Memory System

Wait for the memory system to complete initialization (first time may take a few minutes)

Step 4

Test Features

Try using core features to ensure everything is working properly

Frequently Asked Questions

Q: Is Personal AI free?

A: Yes, Personal AI is completely free. However, some features require your own AI service API keys (such as OpenAI API).

Q: Which browsers are supported?

A: Currently supports Chrome and Chromium-based browsers (such as Edge, Brave, etc.). Recommended Chrome version 90+.

Q: Will my data be leaked?

A: Personal AI processes all data locally, and does not upload your chat records, memory data, etc. to any external servers. Please refer to our Privacy Policy.

Q: How to update the extension?

A: Extensions installed from Chrome Web Store update automatically. Manual installations require re-downloading and loading the new version.

Q: Extension doesn't work?

A: Please check: 1) Extension is enabled 2) Necessary permissions are granted 3) Chrome version is supported 4) Try restarting browser.

Q: Where to get help?

A: View full documentation or submit issues on GitHub.
