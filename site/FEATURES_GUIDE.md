# Personal AI 网站功能使用指南

## 🌐 多语言切换

### 功能位置
导航栏右上角，显示为带有地球图标的按钮，当前语言标识（"EN" 或 "中文"）

### 使用方法
1. 点击语言切换按钮
2. 页面自动刷新所有文本为目标语言
3. 语言选择会被保存到浏览器本地存储
4. 下次访问会自动应用上次选择的语言

### 支持的语言
- 🇨🇳 简体中文 (zh-CN)
- 🇺🇸 English (en)

### 自动检测
首次访问时，系统会：
1. 检查是否有保存的语言偏好
2. 如果没有，根据浏览器语言自动选择
3. 中文浏览器 → 中文界面
4. 其他语言浏览器 → 英文界面

## ✨ AI 头像版本切换

### 功能位置
首页英雄区，AI 头像 Canvas 下方的切换器面板

### 三个版本对比

#### 版本 1: 优化粒子系统 (推荐)
```
特点：流畅、优雅、平衡
适合：所有设备
粒子数：600 (桌面) / 300 (移动)
```

**优势**：
- ✅ 性能优化，无卡顿
- ✅ 流畅的水波交互
- ✅ 发光粒子效果
- ✅ 呼吸式动画

**交互**：
- 鼠标悬停产生水波涟漪效果
- 粒子被推开后自动回归
- 眼睛区域持续发光

---

#### 版本 2: 全息砖块投影 (最炫酷)
```
特点：科技感、全息投影、未来风格
适合：现代浏览器
砖块数：~200
```

**优势**：
- ✅ 独特的半透明砖块设计
- ✅ 全息投影视觉效果
- ✅ 扫描线动画
- ✅ 砖块闪烁和漂浮

**效果**：
- 半透明发光砖块组成头部轮廓
- 砖块随机闪烁（类似数据流）
- 扫描线从上到下移动
- 虚线边框营造全息感
- 鼠标悬停推开砖块

**最佳观看距离**：桌面端全屏

---

#### 版本 3: 3D 线框网格 (最流畅)
```
特点：3D、线框、极简、高性能
适合：所有设备，特别是低性能设备
网格节点：~150
```

**优势**：
- ✅ 真正的 3D 投影效果
- ✅ 可跟随鼠标旋转
- ✅ CPU 占用最低
- ✅ 极简科技美学

**交互**：
- 鼠标移动控制 Y 轴旋转
- 自动缓慢旋转（无鼠标时）
- 扫描线效果
- 前后遮挡（深度感）

**技术亮点**：
- 3D 球形网格映射
- 实时透视投影计算
- 背面剔除优化

---

### 如何切换版本

1. **找到切换器**
   - 位置：AI 头像正下方
   - 标签：显示 "头像版本:"
   
2. **点击按钮**
   - V1: 粒子
   - V2: 全息
   - V3: 线框

3. **查看效果**
   - 立即切换，无需刷新
   - 选择会被保存
   - 下次访问自动应用

### 推荐场景

| 场景 | 推荐版本 | 原因 |
|-----|---------|------|
| 日常使用 | V1 | 最佳平衡 |
| 演示展示 | V2 | 最吸引眼球 |
| 低配设备 | V3 | 最流畅 |
| 触摸设备 | V1 或 V3 | 交互友好 |
| 4K 屏幕 | V2 | 细节丰富 |

## 📱 响应式设计

### 桌面端 (≥1024px)
- 双列布局（头像 + 文字）
- 完整动画效果
- 所有粒子和连接线
- 最佳视觉效果

### 平板端 (768px - 1023px)
- 单列布局
- 优化的动画效果
- 降低粒子数量
- 保持流畅性

### 移动端 (<768px)
- 纵向排列
- 大幅降低粒子数量
- V1 版本不显示连接线
- 汉堡菜单导航

## 🔧 性能优化建议

### 如果遇到卡顿：
1. 切换到 V3（线框版本）
2. 关闭其他占用资源的浏览器标签
3. 更新到最新版本的浏览器
4. 启用硬件加速（浏览器设置）

### 性能检查
打开浏览器控制台 → Performance 标签 → 录制页面性能

理想状态：
- FPS: 60
- CPU: <30%
- 内存: <100MB

---

## 🐛 故障排查

### 语言切换不工作
1. 确保浏览器支持 localStorage
2. 检查是否禁用了 JavaScript
3. 清除浏览器缓存后重试

### AI 头像不显示
1. 检查浏览器是否支持 Canvas
2. 确保 JavaScript 已启用
3. 查看浏览器控制台是否有错误

### 版本切换无响应
1. 刷新页面
2. 清除浏览器缓存
3. 尝试其他浏览器
