安装指南

两种方式开始使用 Personal AI

1

从 Chrome 商店安装

推荐

最简单的安装方式，一键安装，自动更新。

1

访问 Chrome 商店

点击下方按钮或访问链接打开扩展页面

打开 Chrome 商店
2

点击"添加至 Chrome"

在扩展页面点击蓝色的安装按钮

3

确认安装

在弹出的对话框中点击"添加扩展程序"

4

开始使用

安装完成后，点击浏览器右上角的扩展图标即可使用

2

从源码构建安装

开发者

适合开发者或想要使用最新功能的用户。

前置要求

  • Node.js 16+ 和 Yarn
  • Docker（用于 ChromaDB 向量数据库）
  • Git

安装步骤

1

克隆仓库

git clone https://github.com/your-repo/personal-ai.git cd personal-ai
2

安装依赖

yarn install
3

配置环境变量

从 .env.example 创建 .env.development 文件

cp .env.example .env.development

编辑 .env.development 文件，填入必要的 API 密钥和配置

4

启动 ChromaDB 向量数据库

使用便捷脚本启动（推荐）：

chmod +x chroma.sh ./chroma.sh start

或使用 Docker Compose：

docker-compose up -d
5

构建扩展

开发模式（自动重新编译）：

yarn start

或生产构建：

yarn build
6

加载到 Chrome

  1. 打开 Chrome，访问 chrome://extensions/
  2. 开启右上角的"开发者模式"
  3. 点击"加载已解压的扩展程序"
  4. 选择项目中的 dist 文件夹
  5. 扩展已加载，可以开始使用了

数据备份

定期备份 ChromaDB 数据：

tar -czf ./chroma-backup/chroma-backup-$(date +%Y%m%d).tar.gz ./chroma-data

数据迁移

从备份恢复数据：

python3 -m venv venv source venv/bin/activate pip install -r requirements.txt python tools/migrate_chroma_via_http.py

常见问题

为什么需要安装 ChromaDB？

ChromaDB 是 Personal AI 的核心组件，用于存储和检索记忆数据。它提供了强大的向量搜索能力，让 AI 能够快速找到相关信息。

扩展需要哪些权限？

Personal AI 需要访问特定网站（如 Jira、Google Slides）的权限，以及存储权限来保存您的数据。所有权限都仅用于提供功能，不会收集或泄露您的隐私信息。

数据存储在哪里？

所有数据都存储在您的本地设备上。ChromaDB 数据库运行在您的计算机上，我们不会将您的数据上传到任何服务器。

如何更新扩展？

从 Chrome 商店安装的扩展会自动更新。如果是从源码安装，需要手动拉取最新代码并重新构建。
