隐私政策

我们重视并保护您的隐私

最后更新：2025年5月

重要声明

Google Workspace APIs 不用于开发、改进或训练通用 AI 和/或 ML 模型。

Personal AI 严格遵守 Google API 服务用户数据政策和限制使用要求。

数据访问范围

Personal AI 通过 Google Sheets API 访问有限的 Google 用户数据。具体来说，它可能访问用户通过 Google OAuth 明确授权的电子表格内容，目的是创建、更新和管理用户的定时消息数据表。

不会访问以下数据：

  • Gmail 邮件内容
  • Google Drive 文件（除授权的 Sheets）
  • Google Calendar 事件
  • 其他 Google 账户数据

数据使用方式

访问的 Google Sheets 数据仅用于启用和管理定时消息功能，该功能允许用户存储和修改消息调度信息。

Personal AI 不会将 Google 用户数据用于：

  • 广告投放
  • 数据挖掘
  • 与功能性能无关的分析
  • 训练通用 AI 或 ML 模型

所有操作严格限制在用户在应用程序中请求的功能范围内。

数据共享政策

Personal AI 不与任何第三方共享通过 Google Sheets API 获得的用户数据。

数据仅在用户账户范围内使用，用于定时消息功能的运行。Personal AI 不会出售、租赁或以其他方式将用户数据分发给外部实体。

数据可能仅在以下情况下与 Google APIs 共享：

  • Google 服务功能所必需的
  • 始终符合 Google API 服务用户数据政策
  • 始终符合限制使用要求

数据存储与保护

所有访问的 Google Sheets 数据都按照行业标准安全存储。

安全措施包括：

  • 应用程序和 Google APIs 之间的数据传输使用 HTTPS
  • 使用 OAuth 2.0 进行身份验证
  • 任何本地缓存的数据在传输和静态时都加密
  • 访问令牌安全存储，仅在必要时刷新以维护功能
  • 应用程序实施最小权限访问控制
  • 定期审查权限以确保合规性和安全性

数据保留与删除

Google 用户数据仅在支持用户的定时消息功能所需的时间内保留。

数据删除方式：

  • 当用户撤销 Google 授权时，所有相关的 Google Sheets 访问令牌和本地存储的数据将立即删除
  • 当用户删除其账户时，所有相关数据将被删除
  • 用户可以随时联系支持请求删除其相关数据

Personal AI 确保符合 Google 的数据删除要求和适用隐私法律下的用户数据权利。

本地数据存储

Personal AI 使用本地 ChromaDB 向量数据库存储您的记忆数据。

存储特点：

  • 所有数据都存储在您的本地计算机上
  • 我们不会将您的数据上传到任何远程服务器
  • 您完全控制自己的数据
  • 可以随时备份或删除本地数据

您的权利

作为 Personal AI 的用户，您拥有以下权利：

  • 访问权：您可以随时查看我们存储的关于您的数据
  • 删除权：您可以请求删除您的所有数据
  • 撤销授权：您可以随时在 Google 账户设置中撤销对 Personal AI 的授权
  • 数据导出：您可以导出您的本地数据
  • 限制处理：您可以限制我们处理您数据的方式

联系我们

如果您对本隐私政策有任何疑问，或想行使您的数据权利，请通过以下方式联系我们：

  • Email: privacy@personalai.com
  • GitHub Issues: 提交问题

政策更新

我们可能会不时更新本隐私政策。我们将通过以下方式通知您任何变更：

  • 在扩展程序中显示通知
  • 更新本页面的"最后更新"日期
  • 通过 Email 通知重大变更

继续使用 Personal AI 即表示您接受更新后的隐私政策。
