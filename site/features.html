功能结构

围绕真正需要上下文的现场组织私人记忆能力。

记忆核心

基础层

Memory Service 把消息、会议、网页资料、实体关系、用户画像和 source capsule 组织成私人长期记忆层。

  • 语义、关键词、图谱和时间四通道召回
  • 显著性评分、衰减、巩固、反思和原始证据保留
  • 按用户隔离，并尊重工作、个人、全部等范围语义

记忆捕捉

入库

以低打扰方式保存真正重要的资料，同时避免把普通浏览历史变成噪音。

  • 保存选中文本、整页网页、表格、SVG/视觉区域和 Jira owner comment
  • 保存来源、原因、证据锚点、takeaways、future triggers 和可撤销事件
  • 用建议入库和自动入库门槛控制误捕捉

记忆提示

召回

在当前网页、消息、Jira、会议或划词现场，把真正相关的旧记忆带回来。

  • 右下角轻提示、hover peek 和展开卡片三层交互
  • 划词记忆检索支持用户主动查询选中文本
  • 展示来源链接、匹配原因、反馈、站点静默和敏感页面拦截

回复助手

写作

用记忆在原生输入框旁生成可插入文本，但不替用户发送。

  • 支持 RingCentral 回复、Jira comment 和 Web AI 输入框
  • 生成回复草稿或 context pack，并按风险要求预览确认
  • 从脱敏改写 trace 学习写作风格，而不是保存最终发送原文

今天与会议

准备

把每天和每场会议压缩成少量有证据、有下一步的提示。

  • 今日 Mission 来自会议、提醒、动作、人脉信号和项目风险
  • 会前准备可以交接到 RingCentral 会议捕获和侧边面板
  • 会中行动项、决议、时间线、摘要和会后 Panorama 可复盘

Ask 与探索

查询

主动向自己的记忆提问，并能回看答案背后的证据链。

  • 短问题会先做话题锁定，例如“那个 BE ready 了吗”
  • 答案基于本次证据，证据不足时保留 unknown 或转外部查证
  • 搜索结果、时间轴、资料详情、动作队列和决策中心可追溯

项目与人脉

工作上下文

整理长期项目和人物上下文，同时不把推断信号伪装成已确认事实。

  • 项目面板显示本地计划、证据覆盖、风险线索和 Memory Service 关注项目同步
  • 人脉雷达整理最近互动、未闭环事项、context card 和 meeting brief
  • 敏感或推断关系事实保留安全链接和确认 / 驳回路径

覆盖与控制

信任

看清 Personal AI 当前看得见什么、哪些来源变旧、哪些动作需要用户明确控制。

  • Memory Coverage Map 展示平台健康、质量分、修复队列和资料录入
  • 备份恢复、隐私控制、来源链接和站点级静默 / 屏蔽列表
  • 只在对外发送、不可逆删除、稳定画像等高责任边界要求用户确认
