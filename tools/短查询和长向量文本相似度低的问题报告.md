## 💡 核心问题

### 1. 信息密度失衡
- **查询**：13字符，信息密度高（100%有效）
- **存储**：430字符，信息密度低（目标关键词占比 <5%）

### 2. 语义漂移
长文档中的大量"噪音"词汇（如人名、其他话题）稀释了核心关键词的语义权重。

### 3. 向量编码特性
Sentence-Transformers 的 all-MiniLM-L6-v2 模型：
- 对短文本：每个词的权重都很高
- 对长文本：权重被分散到所有词上
- 结果：长文本的核心关键词向量权重被稀释

### ✅ 可行的解决方案

#### 方案 A：元数据精确过滤 + 向量搜索（推荐⭐⭐⭐）

```python
def smart_search(query, collection):
    # 1. 提取查询中的关键词
    keywords = extract_keywords(query)  # ["alex", "9月", "厦门", "行程"]
    
    # 2. 先用元数据过滤缩小范围
    # 在name字段中查找包含任意关键词的实体
    filtered_ids = []
    for kw in keywords:
        result = collection.get(
            where={"name": {"$contains": kw}},  # 如果ChromaDB支持
            include=['metadatas']
        )
        filtered_ids.extend(result['ids'])
    
    # 3. 在过滤后的结果中做向量搜索
    if filtered_ids:
        result = collection.query(
            query_embeddings=[embedding],
            n_results=10,
            where={"id": {"$in": filtered_ids}}  # 只在过滤结果中搜索
        )
    else:
        # Fallback到全局搜索
        result = collection.query(query_embeddings=[embedding], n_results=10)
```

**优点**：
- ✅ 可以直接定位到相关实体
- ✅ 缩小搜索空间，提高准确率
- ✅ 兼顾精确匹配和语义搜索

**缺点**：
- ⚠️ 依赖ChromaDB的元数据查询能力
- ⚠️ 需要设计关键词提取策略

#### 方案 B：BM25 + 向量混合搜索（推荐⭐⭐）

```python
from rank_bm25 import BM25Okapi

def hybrid_search(query, collection, alpha=0.5):
    # 1. 获取所有文档
    all_docs = collection.get(include=['documents', 'metadatas'])
    
    # 2. BM25 关键词搜索
    corpus = [doc.lower().split() for doc in all_docs['documents']]
    bm25 = BM25Okapi(corpus)
    bm25_scores = bm25.get_scores(query.lower().split())
    
    # 3. 向量搜索
    vector_result = collection.query(
        query_embeddings=[embedding],
        n_results=len(all_docs['ids'])
    )
    vector_scores = [1 - d for d in vector_result['distances'][0]]
    
    # 4. 混合评分
    final_scores = []
    for i in range(len(all_docs['ids'])):
        # 归一化BM25分数
        bm25_norm = bm25_scores[i] / max(bm25_scores)
        # 混合
        final_score = alpha * vector_scores[i] + (1 - alpha) * bm25_norm
        final_scores.append((all_docs['ids'][i], final_score, all_docs['metadatas'][i]))
    
    # 5. 排序并返回Top K
    final_scores.sort(key=lambda x: x[1], reverse=True)
    return final_scores[:10]
```

**优点**：
- ✅ BM25对关键词匹配非常准确
- ✅ 结合向量的语义理解
- ✅ 可调节 alpha 控制精确性/语义性的权衡

**缺点**：
- ⚠️ 需要加载所有文档到内存（11794个实体）
- ⚠️ 首次搜索较慢
- ⚠️ 需要额外的依赖（rank-bm25）

#### 方案 D：修改存储策略 - 双向量索引（长期⭐⭐⭐）

1. **短描述**（用于快速匹配）
   ```

   ```

2. **完整描述**（用于语义理解）
   ```

   ```

- 短查询 → 搜索 short embeddings
- 长查询/复杂问题 → 搜索 full embeddings

**优点**：
- ✅ 从根本上解决问题
- ✅ 支持不同粒度的查询
- ✅ 最佳用户体验

**缺点**：
- ❌ 需要重构存储逻辑
- ❌ 需要重新索引所有数据（11794个实体）
