# ChromaDB 语义搜索工具 - 中文使用说明

## 🎯 这是什么？

一个强大的命令行工具，可以用自然语言搜索你的 ChromaDB 数据库。

支持搜索：
- 💬 **消息（messages）** - 聊天记录、讨论内容
- 👤 **实体（entities）** - 人员、项目、组织、主题等
- 🌐 **网页（webpages）** - 收藏的网页、文档

---

## ⚡ 4 步开始使用

### 第 1 步：安装依赖

```bash
# 激活虚拟环境
source venv/bin/activate

# 安装必要的依赖（包含嵌入模型）
pip install -r requirements.txt
```

**注意**：首次运行会自动下载嵌入模型（约 90MB），请确保网络连接正常。

### 第 2 步：启动数据库（如果还没启动）

```bash
docker-compose up -d
```

### 第 3 步：开始搜索

```bash
python tools/semantic_search.py "项目进度"
```

就这么简单！

---

## 📖 快速示例

### 查看有哪些数据

```bash
python tools/semantic_search.py --list-collections
```

### 基础搜索

```bash
# 搜索所有类型的数据
python tools/semantic_search.py "技术讨论"

# 只搜索消息
python tools/semantic_search.py "会议记录" --type messages

# 只搜索人员和项目
python tools/semantic_search.py "张三" --type entities

# 只搜索网页
python tools/semantic_search.py "技术文档" --type webpages
```

### 控制输出

```bash
# 只显示 5 条结果
python tools/semantic_search.py "项目" --limit 5

# 输出 JSON 格式（便于程序处理）
python tools/semantic_search.py "项目" --format json

# 保存结果到文件
python tools/semantic_search.py "Q4目标" --output results.json
```

### 连接远程服务器

```bash
# 连接生产环境
python tools/semantic_search.py "查询内容" --host 10.32.56.212 --port 8000
```

## 🎯 常见使用场景

### 场景 1：找某个人的信息

```bash
# 找实体
python tools/semantic_search.py "张三" --type entities

# 找相关讨论
python tools/semantic_search.py "张三的工作" --type messages --limit 10
```

### 场景 2：查项目资料

```bash
# 找项目
python tools/semantic_search.py "AI项目" --type entities

# 找项目讨论
python tools/semantic_search.py "AI项目进度" --type messages

# 导出项目数据
python tools/semantic_search.py "AI项目" --output ai_project.json
```

### 场景 3：找技术资料

```bash
# 找讨论
python tools/semantic_search.py "React Hooks" --type messages

# 找文档
python tools/semantic_search.py "React 文档" --type webpages

# 找所有相关的
python tools/semantic_search.py "React" --limit 20
```

### 场景 4：找会议记录

```bash
# 找周会
python tools/semantic_search.py "周会" --type messages

# 找评审会议
python tools/semantic_search.py "产品评审" --type messages
```

## 💡 搜索小技巧

### ✅ 好的查询方式

- "React 组件优化方案"（具体、描述性）
- "张三负责的前端项目"（明确上下文）
- "数据库索引设计讨论"（清楚的主题）

### ❌ 不好的查询方式

- "React"（太宽泛）
- "讨论"（缺少上下文）
- "项目"（不够具体）

### 💡 提示

1. 使用完整的短语比单个词效果好
2. 语义搜索不需要精确匹配，相近的词也能找到
3. 先用小的 `--limit` 值快速测试
4. 用 `--type` 参数可以大大提高搜索速度

---

## 🔧 所有参数

| 参数 | 说明 | 示例 |
|------|------|------|
| 查询内容 | 要搜索的内容（必需） | `"项目进度"` |
| `--type` | 数据类型 | `messages` / `entities` / `webpages` |
| `--collections` | 指定集合 | `esone.qiu-messages` |
| `--limit` | 返回结果数量 | `10` |
| `--format` | 输出格式 | `text` / `json` |
| `--output` | 保存到文件 | `results.json` |
| `--host` | 服务器地址 | `localhost` |
| `--port` | 服务器端口 | `8000` |
| `--list-collections` | 列出所有集合 | - |

## ❓ 遇到问题？

### 连接失败

```bash
# 检查服务状态
docker-compose ps

# 重启服务
docker-compose restart chroma
```

### 找不到结果

- 试试更宽泛的查询词
- 检查数据类型是否正确
- 看看是否有数据：`python tools/semantic_search.py --list-collections`

### Python 错误

```bash
# 确保激活了虚拟环境
source venv/bin/activate

# 重新安装依赖
pip install -r requirements.txt
```
