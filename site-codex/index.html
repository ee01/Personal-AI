What it does

Complete Personal AI surface

Built from the chrome extension codebase: message intelligence, Jira helpers, Google Slides analyzers, and a brain-like memory system.

AI Filters

Message analysis & filtering

LLM-powered triage with entities, relevance scoring, @me rules, and personalized notifications. Supports silent mode, batch processing, and reply suggestions.

  • Context-aware importance & tone
  • Custom concerned items + XML import/export
  • Stores highlights to Chroma for retrieval
Agent Thinking

Thought-action loop

Single smart agent with tool registry (entity extraction, history search, JIRA query, notifications, memory store) that iterates until it has enough signal.

  • Strongly typed results per content type
  • Multi-tool reasoning with confidence data
  • Batch analyze messages, projects, webpages
Agent Workflow

Multi-agent orchestration

Coordinator dispatches specialized agents: entity recognizer, notification judge, relationship analysis, importance scorer, external queries, reply adviser.

  • Prioritized execution and fault isolation
  • LLM-based concerned-item matching
  • @me aware Glip bot delivery
Memory

Hybrid memory system

Cloud-first vector storage + local cache with CachedEntityDetail. Unified entities, relationships, recency data, and health monitoring.

  • Chroma collections for messages, webpages, graph entities
  • Similarity detection and auto-merge candidates
  • User profile with explicit interest weighting
Slides

Google Slides analyzer

Scans project decks, extracts Jira IDs, statuses, owners, and suggests updates. Uses Slides API plus optional LLM fallback for messy layouts.

  • Table, text, and list parsing with confidence
  • Applies updates back to slides after review
  • Finds hidden risks from chat and Jira history
Jira

Jira design + automation helpers

Auto-injects design links (Figma/UX tickets) on Jira pages and adds Import rule to Automation pages with JSON conversion and API calls.

  • Epic/Parent/Linked issue traversal
  • Source labels and hover reveals
  • Configurable custom field mappings

Analysis modes

Choose how the agent thinks

Switch per environment: deep autonomous thinking, lean multi-agent workflow, or classic LLM pass. All honor the same notification and memory plumbing.

Deep reasoning

Runs a thought → decide → tool → reflect loop with explicit tool usage stats, token counts, and confidence. Ideal for complex threads or project reviews.

  • Dynamic tool ordering and early stopping
  • Per-item results: relevance, entities, shouldStore, actions
  • Visualizer hooks for thought steps

Multi-agent speed

Coordinator dispatches specialized agents in priority order to keep latency low while preserving accuracy. Perfect for continuous silent analysis.

  • Entity → notify → relation → importance → external → reply
  • Confidence-aware matching of concerned items and @me
  • Graceful degradation when a tool fails

Classic LLM pass

A lightweight single-shot analysis that still supports batching, group scoping, and configurable LLM providers. Great for fast dev loops.

  • Lower resource use
  • Group-aware summaries and reply suggestions
  • Plugs into the same notification + storage path
Signal pipeline
  1. Capture: chat, Jira, Slides, webpages
  2. Understand: entity extraction + relevance + sentiment
  3. Decide: importance, @me, shouldNotify/shouldStore
  4. Act: Glip bot, @me mentions, reply advice
  5. Store: vector DB + graph relations + cache
  6. Learn: user profile weighting & decay

Memory & knowledge

Brain-like memory built with Chroma + local cache

Unified interfaces route reads and writes, auto-extend entities with recent conversations, webpages, projects, participants, and resources.

Storage architecture

Cloud-first Chroma collections with paging, plus Chrome storage cache that keeps the UI sub-2s. Health checks, sync jobs, and backup hooks included.

  • Collections: messages, webpages, graph-entities
  • EntitySimilarityTool for merge candidates
  • SystemMaintenanceTool with cleanup & reports

User profile engine

Tracks behaviors (view, edit, create, search) with explicit importance sliders and adaptive weight decay. Exports full profile JSON on demand.

  • Interests across projects, people, topics, docs, tickets
  • Explicit vs. implicit weighting with decay preview
  • Feeds Web Intelligence for personalized relevance

Visual intelligence

Entity list and detail pages use CachedEntityDetail: includes recent conversations (with highlights), webpages, related projects, and participants.

  • Relationship graphs & timeline-ready data
  • Automatic importance scoring and tags
  • API-ready interfaces for other modules

Install & setup

Ship in minutes or develop locally

Quick install (Chrome Web Store)

  1. Open the store listing and click Add to Chrome.
  2. Pin the icon, right-click > Options, set your Dify API Key.
  3. Enable 静默定时消息分析 and configure your concerned topics.
  4. Done — silent monitoring, Glip pushes, and knowledge queries are live.

Developer setup

  1. Install deps: yarn install
  2. Start Chroma vector DB: 
    chmod +x ./chroma.sh
./chroma.sh start
    or docker-compose up -d.
  3. Create .env.development from the example, set GOOGLE_CLIENT_ID (test client).
  4. Dev build: yarn start (webpack watch). Load dist as unpacked extension in Chrome.
  5. Production: yarn build then load/pack dist or upload personal-ai.zip.
