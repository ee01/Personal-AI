What we collect

Only what is needed to deliver the features you enable

Drawn from the extension and the PRIVACY NOTICE: the service is intended for business use and processes data you explicitly allow.

Operational data

  • Messages and thread context for analysis, @me detection, and summaries.
  • Entities and metadata (people, projects, topics, timestamps, links).
  • Webpages and Slides content you open when analysis is triggered.
  • Notification targets you configure (Glip, @me flags).

Storage choices

  • Cloud: Chroma vector collections for messages/webpages/entities.
  • Local: Chrome storage cache for fast UI (recent conversations, pages).
  • Backups: optional tar backups of chroma-data you run locally.
  • Healthy by design: scheduled cleanup, similarity merges, health checks.

Not used for generalized AI

From the May 2025 update: Google Workspace APIs are not used to develop, improve, or train generalized AI/ML models.

  • LLM calls are limited to the provider you configure.
  • Data stays within the configured stores; no resale of data.
  • You may disable storage or notifications at any time.

How it is used

Purpose-bound processing

  • Message analysis: determine relevance, entities, actions, and whether to notify or store.
  • Memory & recall: save important items to ChromaDB + cache for fast retrieval and dashboards.
  • Notifications: deliver Glip bot messages or @mentions only when rules match.
  • User profile: maintain interest weights to personalize results; exportable on request.
  • Slides/Jira helpers: read and optionally write updates you approve (Slides API updates, Jira automation import).

User controls

  1. Disable silent analysis or notifications from Options at any time.
  2. Edit or remove concerned items; export/import XML configs.
  3. Export user profile JSON and Chroma data backups you own.
  4. Clear local cache; run maintenance to purge expired items.
  5. Choose LLM provider and enable/disable send-before-review gates.

Security

Designed with operational safeguards

Grounded in the notice and system design: least-privilege APIs, health monitoring, and clear termination paths.

Safeguards

  • Health checks for cloud and cache connectivity with scored status.
  • Automatic cleanup of expired cache entries and relationship data.
  • Error isolation per agent/tool; graceful degradation to avoid over-notifying.
  • Manual maintenance hooks for cleanup, sync, and backups.
