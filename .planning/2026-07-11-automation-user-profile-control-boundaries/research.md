# Research Notes

- OpenAI Memory FAQ, updated 2026-07-09: memory controls live in personalization settings; the memory summary can be edited, corrected, searched/sorted, prioritized/deprioritized, deleted, and restored, but it is still a high-level view rather than every underlying source.
- Claude Help Center, updated 2026-07-11: memory import/export supports migration and backup; users can view/edit memory and imported memory may be incomplete, so manual correction remains important.
- Response-Aware User Memory Selection for LLM Personalization, 2026: selecting profile memories only by semantic similarity is weaker than selecting memories that improve response utility.
- MemFlow, 2026: memory operations should be routed by intent into profile lookup, targeted retrieval, or deep reasoning with different evidence budgets.
- Mem0, 2025, and MemoryBank, 2023/2024: long-term AI memory relies on dynamic extraction, consolidation, retrieval, user portraits, reinforcement, and forgetting, so UI should separate current visible slice from the whole memory/profile state.
